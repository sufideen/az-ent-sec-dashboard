Secure AKS Web Platform

This static page is served from a container built and pushed to Azure Container Registry by GitHub Actions, deployed to a private Azure Kubernetes Service cluster, and exposed to the Internet through an Application Gateway (WAF_v2) ingress.

  • No public AKS API server
  • No ACR admin credentials - image pulls use the node's managed identity
  • GitHub Actions authenticates to Azure via OIDC - no stored secrets
  • Runs as a non-root user with a read-only root filesystem
